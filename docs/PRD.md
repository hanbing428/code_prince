# 产品需求

## 已确认定位

2026-11-05：用户确认需求分析与项目规则方案，要求暂不接后端，所有接口位置保留，使用静态数据模拟。当前授权为本地文档、Skill、前端和模拟流程实现。

目标用户是已逝宠物的主人与亲友。以私人纪念为主，默认私密，可主动公开分享；首版免费，视觉温柔、安静、尊重。主流程：创建纪念馆 → 照片与故事 → 祭奠留言 → 亲友访问。

## 业务规则

- 纪念馆由一个创建者管理，亲友不共编。访客不自动获取模拟用户身份。
- 公开仅表示可通过分享访问，首版不构建搜索和公共广场。演示首页可展示一个公开样例入口。
- 纪念天数按日期计算，未知日期显示“日期不详”，不强迫填写虚构日期。
- 每次成功祭奠是一条记录，不设置排行榜或付费项目。
- 本地模拟账号、媒体路径、审核与存储供前端体验。服务端鉴权、存储备份、真实注销与内容安全接入待后端阶段实现。
- 不声称本地前端权限具有防篡改能力。管理员演示身份明确标识，未来不得保留为生产入口。
