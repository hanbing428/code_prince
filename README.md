## 当前项目：pet_system_uni

宠物云祭奠与回忆保存小程序，页面临时名称为“念念”。面向已逝宠物的主人与亲友，私人纪念优先、默认私密、免费，可由馆主主动公开分享。

当前为 uni-app + Vue 3 + JavaScript 的本地模拟版本，共 6 个业务页面、29 个预留异步接口。已实现模拟身份、纪念馆增改删、单图回忆、免费祭奠、留言举报、隐私切换、账号注销和管理演示。

所有业务数据仅保存在当前设备，新增内容不能跨设备访问；图片使用临时路径，不能作为长期备份。尚未接入真实后端或微信登录，尚未通过微信开发者工具、真机及用户人工验收，未发布。

## 运行与验证

1. 使用 HBuilderX 打开项目根目录。
2. 通过“运行到浏览器”体验本地模拟流程；“我的”页面可切换宠物主人、亲友和管理员演示身份。
3. 运行到微信开发者工具需使用有效的微信小程序 AppID；当前 `manifest.json` 中 `mp-weixin.appid` 为空。

本项目沿用 HBuilderX 项目结构，没有独立 npm 构建脚本。接口行为测试使用 Node.js 22：

```powershell
node --experimental-default-type=module --test tests/api.test.mjs
```

编译器检查及浏览器适配预览说明见 [测试与验收](docs/TESTING.md)。预览适配器通过不等于 uni-app 构建或微信真机验收通过。
